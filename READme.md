# Remove Duplicates Program

This Python program removes duplicate values from a list while preserving the original order of the items.

## Features
- Accepts a list of values
- Removes repeated values
- Keeps the first occurrence of each item
- Prints both the original and the unique list

## How to Run
1. Open the project folder in Python.
2. Run the script:
   ```bash
   python remove_duplicates.py
   ```

## Example
Input list:
```python
[10, 20, 10, 30, 40, 20, 50, 30]
```

Output:
```python
Original List : [10, 20, 10, 30, 40, 20, 50, 30]
Unique List   : [10, 20, 30, 40, 50]
```
