[✓] Min-Max Scaling Explanation
    Formula: (value - minimum) / (maximum - minimum)
    
    Purpose:
    - Normalizes data to range [0, 1]
    - Preserves the distribution shape
    - Useful for bounded outputs
    
    Advantages:
    - Simple to understand and implement
    - Bounded output between 0 and 1
    - Useful for neural network activations
    
    Disadvantages:
    - Sensitive to outliers
    - Range depends on min/max values
    - Not suitable if min/max might change in new data
    
    When to Use:
    - Neural networks (especially with sigmoid activation)
    - Image processing (0-1 or 0-255 range)
    - When bounded output is required

[✓] Z-Score Standardization Explanation
    Formula: (value - mean) / standard_deviation
    
    Purpose:
    - Centers data around 0 with standard deviation of 1
    - Creates comparable scales for different features
    - Useful for statistical algorithms
    
    Advantages:
    - Removes units from data
    - Makes different features comparable
    - Less sensitive to outliers than Min-Max
    - Naturally handles any distribution
    
    Disadvantages:
    - Doesn't bound output to specific range
    - Zero std error for constant datasets
    - Assumes normal distribution for optimality
    
    When to Use:
    - Linear regression
    - Logistic regression
    - Support Vector Machines (SVM)
    - Principal Component Analysis (PCA)
    - K-means clustering

[✓] Why NumPy is Preferable to Manual Python Loops
    
    Performance:
    - NumPy operations are 10-100x faster
    - Implemented in optimized C code
    - Vectorized operations avoid Python interpreter overhead
    
    Memory:
    - NumPy arrays use less memory
    - Contiguous memory layout for better cache performance
    - Efficient data type handling
    
    Code Clarity:
    - Vectorized operations are more concise
    - Easier to understand mathematical intent
    - Reduces code length and complexity
    
    Compatibility:
    - Standard for scientific computing ecosystem
    - Works seamlessly with pandas, scikit-learn, matplotlib
    - Essential for production ML systems
    
    Example Comparison:
    
    Python Loop (Slow):
        result = []
        for value in data:
            scaled = (value - min_val) / (max_val - min_val)
            result.append(scaled)
    
    NumPy Vectorized (Fast):
        result = (data - min_val) / (max_val - min_val)
    
    For 1 million values:
    - Python loop: ~500ms
    - NumPy vectorized: ~5ms
    - Speedup: 100x faster
