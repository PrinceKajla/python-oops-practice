## IMPORTANT CONCEPTS

What is NumPy?
    - Open-source numerical computing library
    - Provides N-dimensional array object (ndarray)
    - Efficient mathematical operations
    - Foundation for ML/Data Science

Why NumPy > Python Lists?
    - 10-100x faster for large datasets
    - Less memory overhead
    - Broadcasting for element-wise operations
    - Vectorized operations (no explicit loops)

Min-Max Scaling vs Z-Score:
    - Min-Max: Bounds values to [0, 1], preserves distribution shape
    - Z-Score: Centers at 0 with std=1, less outlier sensitive
    - Choose based on algorithm requirements

When to Use Each:
    - Min-Max: Neural networks, image processing, probability outputs
    - Z-Score: Linear regression, SVM, PCA, distance-based algorithms
